# 카드 갤러리 UI/UX 다섯 시선 평가 기록 (2026-10-09)

- 대상: `docs/index.html` (5color.airoasting.com 카드 갤러리)
- 목적: 직장인이 업무 카드를 찾아, 지침을 복사하고, Claude·ChatGPT 프로젝트에 붙여넣는 과정을 끊김 없이 만든다.
- 분류: Core Asset (5-Color Harness 대표 산출물의 첫 접점)
- 갱신 기준: 화면 구조나 카드 수가 바뀌면 이 기록의 평가 절차를 다시 돌리고 점수 이력에 한 줄을 더한다.

## 점수 이력

| 회차 | RED 이성 | SILVER 전문가 | BLUE 공감 | GOLD 독자 | 평균 |
|---|---|---|---|---|---|
| 1차 (수정 전) | 6.2 | 7.2 | 7.1 | 7.3 | 7.0 |
| 2차 | 8.1 | 8.4 | 8.3 | 8.6 | 8.35 |
| 3차 | 8.9 | 9.1 | 8.9 | 9.1 | 9.0 |
| 4차 (최종 확인) | 9.2 | 9.2 | 9.3 | 9.2 | 9.2 |

4차 채점에서 남은 지적(제목의 세리프 숫자, lookbehind 정규식, 모바일 탭 순서, 전체 보기 버튼 위치, 용어 통일)은 채점 뒤에 고쳤다. 고친 뒤의 점수는 아직 매기지 않았다.

## 무엇을 바꿨나 (핵심만)

1. **복사까지의 거리.** 첫 화면에 "내 업무 카드 고르기" 버튼을 두었다. 상세 화면의 복사 머리줄은 헤더 아래에 고정해, 어느 스크롤 위치에서도 한 번에 닿는다. 모바일에서는 편집기를 접어 복사 버튼이 첫 화면에 오게 했다.
2. **복사 다음.** "복사한 다음" 안내 상자(Claude, ChatGPT 전환)를 두었다. 복사하면 머리줄이 "다음: Claude 프로젝트 열기 ↗"로 바뀐다.
3. **색과 숫자에 뜻을 주었다.**
   - 비건디 면은 추천 카드에만 쓰고, 나머지 카드는 핑크로 칠했다.
   - 카드는 01부터 25까지 번호 순으로 놓고 묶음 머리로 나눴다.
   - 합격선은 9.5가 아닌 카드에만 적는다. (그리드 위 범례는 평가 뒤 사용자 결정으로 지웠다.)
4. **맛보기.** "시 쓰기"를 "주간 업무보고"로 바꾸고 정본 순서를 지켰다. (카드로 넘어가는 다리 문장은 평가 뒤 사용자 결정으로 지웠다.)
5. **모바일.**
   - 다섯 이름 목록을 넣었다.
   - 칩을 가로 스크롤 한 줄로 늘 보이게 했다.
   - 입력칸을 16px, 터치 영역을 44px로 맞췄다.
   - 머리줄을 두 줄로 나눴다.
6. **접근성.**
   - 포커스 링은 바탕에 맞춰 칠한다.
   - 화면이 바뀌면 포커스를 옮기고, 목록으로 돌아오면 보던 카드로 복귀시킨다.
   - 카드를 버튼 대신 링크로 바꿔 중첩 버튼을 없앴다.
   - 결과 알림은 별도의 polite 영역으로 보낸다.
   - 대비는 모두 AA 이상이다.
7. **기타.**
   - og:url과 og:image를 실제 도메인으로 고치고, canonical을 추가했다.
   - 공유 버튼은 navigator.share를 쓰고, 지원하지 않으면 링크를 복사한다.
   - 지침 전문의 마크다운 기호를 옅게 칠했다. 복사되는 원문은 바뀌지 않는다.

## 평가 뒤 사용자 결정으로 바꾼 것

- 카드 목록 제목을 "어떤 글을 쓰시나요?"에서 "어떤 업무를 하시나요? 카드에서 고르세요."로 바꿨다. 카드는 글 종류가 아니라 업무 단위다.
- 붙여넣기 안내 3단계를 "이제 해당 프로젝트에서 다섯 명을 자유자재로 호출할 수 있습니다."로 바꿨다.
- 노트북 비율 화면(1512×860, 1280×720)에서 사진 아래 이름줄이 잘리던 문제를 고쳤다. 사진 높이를 정할 때 이름줄 높이를 먼저 뺀다.
- 사진과 다섯 이름이 다 보인 뒤 화면 높이의 45%만큼 머무는 구간을 두었다(`--cast-dwell`).

## 일부러 바꾸지 않은 것

- 히어로 일러스트, 3색 팔레트, 데스크톱의 덮으며 올라오는 전환.
- 지침 전문은 원문 그대로 보인다. 보이는 것과 복사되는 것이 같다는 약속을 지킨다.

## 다시 돌리는 법 (평가 절차)

1. 로컬에서 `docs/`를 띄우고(`.claude/launch.json`의 `docs`), 1440×900과 375×812에서 첫 화면, 맛보기, 인덱스, 그리드, 상세(상단, 스크롤 뒤, 복사 직후)를 캡처한다.
2. 관찰 사실(페이지 높이, 복사 버튼 위치, 글자 크기 분포, 대비)을 브리프 한 장에 적는다. 해석은 넣지 않는다.
3. RED, SILVER, BLUE, GOLD 네 평가자에게 같은 브리프와 캡처를 주고 동시에 채점시킨다. GOLD에게는 장면 두 개를 준다. 하나는 노트북을 쓰는 팀장의 5분 과업, 다른 하나는 휴대폰을 쓰는 임원의 30초 과업이다.
4. 여러 평가자가 함께 지적한 순서로 고친다. 고친 내용과 새 캡처를 다음 브리프에 적어 다시 채점한다.
5. 중단 기준. 남은 지적이 콘텐츠 결정이나 범위 밖 작업(정적 경로 생성 등)만 남으면 멈추고, 그 항목을 "남은 일"로 넘긴다.
